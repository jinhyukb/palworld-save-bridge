# Palworld Save Bridge

친구가 **Steam판 팰월드의 로컬 협동 월드**를 열어 줬고 나는 초대 코드로 참여했다면, 친구가 게임을 켜지 않아도 **내 캐릭터로 그 월드를 이어서 플레이**할 수 있도록 돕는 Windows 프로그램입니다. 받은 세이브는 내 PC에서 처리되며 프로그램이 서버에 업로드하지 않습니다.

> **먼저 확인하세요: 이 GitHub 저장소에는 프로그램 소스만 있습니다.** GitHub의 초록색 **Code → Download ZIP**으로 받는 파일은 실행 프로그램이 아닙니다. 일반 사용자는 저장소 오른쪽의 **Releases**에서 `Palworld-Save-Bridge-...-Windows.exe`를 받아야 합니다. Releases에 해당 `.exe`가 아직 없다면 배포자가 실행 파일을 올리기 전이므로 아래 사용 단계를 시작할 수 없습니다. [GitHub의 Releases 안내](https://docs.github.com/en/repositories/releasing-projects-on-github/linking-to-releases)

## 이 프로그램이 필요한 경우

- 친구가 방장이었던 **Windows PC Steam판 로컬 협동 월드**를 내 PC에서 열고 싶다.
- 친구에게 월드 세이브 폴더를 받을 수 있다.
- 함께 플레이하던 **내 캐릭터의 레벨·소지품·팰과 월드의 거점**을 유지하고 싶다.

전용 서버, Xbox/PC Game Pass, 다른 월드로 캐릭터만 옮기기는 현재 지원하지 않습니다. 모든 팰월드 버전의 세이브가 변환되는 것도 아닙니다. 앱이 파일 구조를 확인할 수 없으면 원본을 건드리지 않고 중단합니다.

## 1. 친구에게 월드 폴더 받기

**방장인 친구에게 팰월드를 종료한 뒤 월드 폴더 전체를 보내 달라고 요청하세요.** 방장이 Windows 탐색기의 주소 표시줄에 `%LOCALAPPDATA%\Pal\Saved\SaveGames`를 붙여 넣으면 세이브 위치가 열립니다. 그 아래에서 **방장의 숫자로 된 Steam 계정 폴더 → 함께 플레이한 월드의 긴 영문·숫자 폴더** 순서로 엽니다. 예를 들어 방장이 보내야 할 것은 `%LOCALAPPDATA%\Pal\Saved\SaveGames\<방장 Steam 계정 ID>\<월드 폴더 ID>`에 있는 **마지막 월드 폴더 전체**입니다. `SaveGames` 전체나 Steam 계정 폴더 전체를 보낼 필요는 없습니다. 어느 월드인지 헷갈리면 방장이 게임에서 해당 월드를 저장하고 종료한 뒤 최근 수정된 월드 폴더를 확인하세요.

받은 폴더에는 최소한 다음이 있어야 합니다. 긴 영문·숫자 폴더 이름은 바꾸지 않는 편이 좋습니다.

```text
월드폴더(긴 영문·숫자 이름)/
├─ Level.sav
├─ LevelMeta.sav
└─ Players/
   ├─ (캐릭터 파일).sav
   └─ ...
```

`WorldOption.sav`와 `LocalData.sav`도 있으면 함께 받으세요. `LocalData.sav`는 방장 개인의 지도 기록일 수 있으므로, 나중에 앱에서 **내 PC의 지도 기록**을 선택할 수도 있습니다. 방장은 이 **월드 폴더 자체**를 보내거나, 월드 폴더를 마우스 오른쪽 버튼으로 눌러 ZIP으로 압축해 보내면 됩니다. `Level.sav` 한 파일만으로는 변환할 수 없습니다.

## 2. 프로그램 받기와 실행

1. 이 GitHub 저장소의 **Releases**를 엽니다.
2. 최신 배포판의 **Assets**에서 이름이 `Palworld-Save-Bridge-...-Windows.exe`인 파일을 받습니다. 예: `Palworld-Save-Bridge-0.1.0-Windows.exe`. `Source code (zip)`, `Source code (tar.gz)` 또는 소스 ZIP은 일반 사용자용 실행 파일이 아닙니다.
3. 받은 `.exe`를 **다운로드 폴더나 바탕 화면처럼 파일을 저장할 수 있는 폴더**에 놓고 두 번 클릭합니다. 별도 설치 과정과 Node.js·Python 설치는 필요하지 않습니다.
4. Windows가 제작자를 확인할 수 없다는 경고를 보여줄 수 있습니다. 현재 시험판은 코드 서명이 없습니다. **이 저장소의 Releases에서 직접 받은 파일인지 확인한 경우에만** 경고 내용을 읽고 실행 여부를 결정하세요. Windows의 보안 설정에 따라 서명되지 않은 앱을 실행할 수 없는 PC도 있습니다. 보안 기능을 끄는 방법은 안내하지 않습니다. [Microsoft의 앱 배포·서명 안내](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/publish-first-app)

## 3. 받은 월드 불러오기

1. 앱 첫 화면에서 **폴더 선택** 또는 **ZIP 선택**을 누릅니다. 받은 폴더나 ZIP을 점선 상자에 끌어놓아도 됩니다.
2. 폴더를 선택한다면 `Level.sav`가 **들어 있는 월드 폴더**를 고르세요. `Players` 폴더까지 함께 있어야 합니다.
3. 여러 월드가 발견되면 이어 할 월드를 선택합니다. 앱이 월드 이름과 캐릭터 목록을 읽어 보여 줍니다.
4. 필요한 파일이 없다는 메시지가 나오면 오류에 적힌 파일을 친구에게 다시 받아 **같은 월드 폴더 안**에 넣은 뒤 다시 불러옵니다.

## 4. 내 캐릭터와 이름 선택

1. **플레이할 캐릭터**에서 초대 코드로 참여했을 때 사용하던 **내 캐릭터**를 클릭합니다. **기존 방장** 표시가 붙은 캐릭터는 친구의 캐릭터입니다. 닉네임이 기억나지 않으면 레벨과 소유 팰 수를 비교하고, 확실하지 않으면 친구에게 확인하세요.
2. **새 월드명**, **새 캐릭터명**은 원할 때만 입력합니다. 비워 두면 원래 이름을 유지합니다. 오른쪽 **변환 미리보기**에서 결과를 확인하세요.
3. 지도 기록을 바꾸고 싶다면 **지도 기록 · 저장 위치**를 펼칩니다.
   - **받은 폴더의 지도 기록 유지**: 친구가 보낸 `LocalData.sav`를 사용합니다. 친구의 지도 탐험 상태가 보일 수 있습니다.
   - **내 PC의 지도 기록**: 같은 월드를 이전에 플레이한 내 PC의 기록이 발견되면 목록에서 고릅니다.
   - **내 LocalData.sav 직접 선택**: 내 지도 파일의 위치를 알고 있을 때만 사용합니다. 반드시 **같은 월드에서 내가 사용한 파일**인지 확인하세요.
   - **새 지도 기록으로 시작**: 캐릭터·팰·아이템·월드는 유지하면서 이 PC의 지도 표시 등 로컬 기록은 새로 시작합니다.
4. 필요하면 **결과 저장 위치 → 변경**으로 저장할 폴더를 고릅니다.
5. **변환본 만들기**를 누릅니다. 월드 크기에 따라 시간이 걸립니다. **변환이 완료되어도 아직 게임에는 적용되지 않습니다.** 아래 5단계에서 앱으로 적용하거나 직접 복사해야 팰월드에서 보입니다.

## 5. 결과 확인 후 게임에 적용

변환이 끝나면 **결과 폴더 열기**를 눌러 새 월드 폴더, ZIP, 검증 기록과 안내문을 확인할 수 있습니다. 받은 원본은 그대로 남습니다. 결과는 기본적으로 실행 파일 옆의 `Palworld Save Bridge Data\results`에 저장됩니다. 앱의 **파일 검사 통과**는 실제 게임에서 정상 플레이되는지까지 확인했다는 뜻은 아닙니다.

게임에서 이 월드를 열려면 다음을 진행하세요. **앱의 적용 기능을 권장합니다. 이 방법을 쓰면 파일을 직접 붙여넣을 필요가 없습니다.**

1. **팰월드를 완전히 종료**합니다.
2. 앱 오른쪽 **내 게임에 적용하기**에서 본인이 사용할 **Steam 계정**을 선택합니다. 현재 Steam 계정이라는 표시가 있으면 계정을 확인하기 쉽습니다.
3. 같은 월드가 이미 있으면 앱에 표시된 **기존 월드 이름과 적용 위치**를 확인하고, 맞을 때만 **같은 월드의 기존 세이브를 백업하고 교체합니다**에 체크합니다.
4. **백업 후 게임에 적용**을 누릅니다. 앱이 이전 월드를 백업하고 검사한 뒤 변환본을 적용합니다. Steam 계정이 목록에 없다면 해당 Steam 계정으로 팰월드를 한 번 실행하고 종료한 다음 앱을 다시 열어 보세요.
5. 팰월드를 실행해 **게임 시작**에서 새 월드명을 선택합니다. 초대 코드는 필요하지 않습니다. **내 캐릭터의 이름·레벨·인벤토리·팰·거점**을 확인하세요.

### 직접 복사해서 적용하려면

앱의 **백업 후 게임에 적용**을 사용하지 못할 때만 아래 방법을 쓰세요. 직접 복사하면 앱의 자동 백업·적용 검사·복구 기록을 사용할 수 없으므로, 먼저 기존 세이브를 다른 위치에 복사해 보관해야 합니다.

1. 팰월드를 완전히 종료합니다. 앱에서 **결과 폴더 열기**를 눌러 결과 폴더를 엽니다. 그 안의 **긴 영문·숫자 이름의 월드 폴더**를 찾습니다. `Level.sav`와 `Players`가 바로 그 안에 있어야 합니다. 같은 이름의 `.zip` 파일은 복사 대상이 아닙니다.
2. Windows 탐색기의 주소 표시줄에 `%LOCALAPPDATA%\Pal\Saved\SaveGames`를 붙여 넣고, **내 Steam 계정의 숫자 폴더**를 엽니다. 목적지는 `%LOCALAPPDATA%\Pal\Saved\SaveGames\<내 Steam 계정 ID>\`입니다. 방장의 Steam 계정 폴더에 붙여넣는 것이 아닙니다. 어떤 숫자 폴더가 내 계정인지 확실하지 않으면 앱의 **내 게임에 적용하기**에 표시된 계정 ID를 확인하세요.
3. 목적지에 **같은 이름의 월드 폴더가 이미 있다면** 먼저 그 폴더 전체를 다른 위치에 백업합니다. 기존 폴더의 파일과 변환본을 섞어 덮어쓰지 말고, 백업 후 기존 폴더를 치운 다음 변환된 월드 폴더 전체를 복사합니다.
4. 최종 경로가 `%LOCALAPPDATA%\Pal\Saved\SaveGames\<내 Steam 계정 ID>\<월드 폴더 ID>\Level.sav` 형태인지 확인한 뒤 팰월드를 실행합니다. **게임 시작**에서 변환한 월드를 선택하세요.

**새 캐릭터를 만들라는 화면이 나오거나 팰·아이템이 예상과 다르면, 새 캐릭터를 만들지 말고 게임을 종료하세요.** 아래 방법으로 이전 상태로 되돌릴 수 있습니다. Steam Cloud가 로컬 파일과 클라우드 파일 중 하나를 고르라고 하면 저장 시각을 확인하세요. 어느 쪽이 변환본인지 확신할 수 없다면 선택 전에 백업을 보관하고 도움을 요청하세요.

## 6. 이전 상태로 되돌리기

1. 팰월드를 종료합니다.
2. 앱 위쪽의 **백업 · 복구**를 누릅니다.
3. 월드 이름·적용 날짜·Steam 계정을 확인하고 해당 기록의 **이전 상태로 복구**를 누릅니다. 중단된 작업이라면 **중단된 작업 복구**라고 표시됩니다.
4. 안내를 확인하고 복구를 실행합니다. 앱은 복구 직전의 **현재 진행 상황도 새 백업으로 보관**합니다.

처음에는 내 PC에 없던 월드를 앱으로 추가했다가 복구하면, 그 월드는 게임 목록에서 사라집니다. 방금까지의 진행 파일은 백업에 남습니다. 백업·설정·로그는 실행 파일 옆의 `Palworld Save Bridge Data`에 있으므로 나중에 복구할 가능성이 있다면 이 폴더를 지우지 마세요.

## 자주 묻는 문제

| 화면 또는 증상                             | 해볼 일                                                                                                                                    |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Releases에 `.exe`가 없습니다               | 저장소의 소스만 공개된 상태입니다. 배포자가 Windows 실행 파일을 Release에 올릴 때까지 기다려 주세요.                                       |
| 월드 폴더를 찾지 못합니다                  | 받은 폴더 안에 `Level.sav`, `LevelMeta.sav`, `Players`가 함께 있는지 확인하세요.                                                           |
| 캐릭터를 선택할 수 없습니다                | 해당 캐릭터의 `.sav` 파일이 빠졌을 수 있습니다. 친구에게 `Players` 폴더 전체를 다시 받으세요.                                              |
| **지원하지 않는 세이브 구조**라고 나옵니다 | 게임 업데이트나 알 수 없는 데이터 형식일 수 있습니다. 원본을 보관하고 새 버전 지원을 기다려 주세요. 파일 이름을 바꿔 해결하려 하지 마세요. |
| Steam 계정이 보이지 않습니다               | 사용하려는 계정으로 Steam판 팰월드를 한 번 실행하고 종료한 뒤 앱을 다시 열어 보세요.                                                       |
| **Palworld를 종료해 주세요**라고 나옵니다  | 게임을 완전히 종료한 후 적용 또는 복구를 다시 시도하세요.                                                                                  |
| 창이 실행되지 않거나 Windows가 차단합니다  | 공식 Releases에서 받은 파일인지 확인하세요. Windows의 보안 정책상 서명되지 않은 파일이 차단될 수 있습니다. 배포자에게 문의하세요.          |

오류를 제보할 때는 **오류 문구·발생 단계·게임 버전**을 적어 주세요. **실제 세이브, ZIP, 백업, 로그를 공개 GitHub Issue에 첨부하지 마세요.** 로그에는 내 PC 경로가 담길 수 있습니다.

## 알아두기

- 이 앱이 만든 월드는 친구의 원래 월드와 **자동으로 동기화되지 않습니다.** 서로 다른 월드로 진행됩니다.
- 기존 방장의 캐릭터 데이터는 결과에 남지만, 친구가 새 월드에 자신의 캐릭터로 다시 참가하려면 별도 연결 작업이 필요합니다.
- 기존 길드장 권한을 임의로 바꾸지 않습니다.
- 이 프로그램은 Pocketpair와 무관한 비공식 커뮤니티 도구입니다.

<summary>소스를 직접 실행하거나 빌드하려는 분께</summary>

일반 사용자에게는 위의 **Releases 실행 파일**을 권장합니다. 소스에서 실행하려면 Windows x64, Node.js 22.12 이상, npm이 필요합니다. 저장소 폴더에서 PowerShell을 열고 아래 명령을 차례로 실행하세요.

```powershell
npm ci
npm run setup
npm start
```
