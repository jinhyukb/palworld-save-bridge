A LITTLE GUIDANCE

처음이라면 이렇게 해 보세요.

방장에게 무엇을 받아야 하나요?

Level.sav, LevelMeta.sav, Players 폴더가 들어 있는 월드 폴더 전체를 받아 주세요. 폴더를 ZIP으로 압축해도 됩니다.

어떤 캐릭터를 선택해야 하나요?

친구의 방에 들어가 플레이하던 본인 캐릭터를 선택하세요. 닉네임이 기억나지 않으면 레벨과 소유 팰 수를 확인하세요. 여러 참가자가 있다면 친구에게도 확인해 주세요.

적용 후에는 어떻게 하나요?

Palworld의 게임 시작에서 설정한 월드를 선택하세요. 초대 코드 없이 혼자 입장할 수 있습니다. 캐릭터 생성 화면이 나온다면 새 캐릭터를 만들지 말고 종료한 뒤 백업을 보관해 주세요.

무엇을 지원하나요?

Windows Steam 로컬 협동 월드의 방장 변경을 지원합니다. 실제 파일 구조와 보존 검사를 통과한 세이브만 변환하며, 모든 게임 버전을 지원하는 것은 아닙니다. 전용 서버, Game Pass, 다른 월드로 캐릭터 옮기기는 첫 버전에 포함되지 않습니다.

내 데이터는 어디에 있나요?

파일은 PC 안에서만 처리합니다. 원본, 결과 파일, 적용 전 백업은 서로 분리됩니다. 백업·설정·로그는 실행 파일 옆의 Palworld Save Bridge Data 폴더에 저장됩니다. 이 폴더를 보관하면 다음 실행에서도 복구 기록을 확인할 수 있습니다.

Steam Cloud 충돌이 표시된다면?

클라우드 상태는 이 앱이 변경하지 않습니다. 파일 날짜와 방금 만든 백업을 확인한 뒤 적용한 로컬 세이브를 유지할지 선택하세요. 판단이 어려우면 선택하기 전에 백업 폴더를 따로 보관해 주세요.

오류가 계속된다면

오류 코드와 게임 버전, 발생한 단계를 함께 알려 주세요. 로그에는 로컬 경로가 포함될 수 있으므로 공개하기 전에 확인해 주세요.
